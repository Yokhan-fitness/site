BUFF IT ID

Один вход для сервисов BUFF IT

Аккаунт создаётся на auth.yokhanfitness.ru и открывает подключённые сервисы без повторного ввода пароля в том же браузере. Сайт не хранит пароль и токены.

Открыть BUFF IT Сервисы
Как работает вход
  • Вход один раз через BUFF IT ID.
  • SmartCart и CALLS уже используют общий сеанс.
  • Fitness APP, Day Flow и SmartCart открываются напрямую с тем же BUFF IT ID.

Доступы

Куда можно идти после входа

Первый клик создаёт общий вход. После этого подключённые веб-сервисы должны открываться без новой формы входа в этом же браузере.

User flow

Как человек должен входить

01

Войти на сайте

Кнопка в шапке ведёт на BUFF IT ID. Пароль вводится только на auth.yokhanfitness.ru.

02

Открыть сервис

SmartCart или CALLS видят уже активный вход и используют тот же аккаунт.
