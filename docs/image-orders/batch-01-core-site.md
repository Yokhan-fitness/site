# Image Order Batch 01 -- Core Site

Batch 01 builds the first visual layer of the public BUFF IT site. These images must make the ecosystem feel real before the visitor reads the details.

Do not make "fitness pictures". Make scenes that answer the visitor's hidden questions: "Will this fit my life?", "Can I trust it?", "What happens after I click?", "Is this about normal people or gym theater?"
