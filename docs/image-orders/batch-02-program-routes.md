# Image Order Batch 02 -- Program Routes

Batch 02 covers program pages and route cards. The goal is not to illustrate exercises. The goal is to make each route emotionally legible in one glance.

Every program image should answer: "Is this my problem?", "Will this route respect my starting point?", "Does this look like a life I can actually maintain?"

## Batch 02 Coverage Check

- [ ] Every route has its own buyer emotion, not a generic athletic person.
- [ ] Pull-up/row/split-squat/hinge/leg-raise/push-up/dip/carry/swing/press/mobility vocabulary is available across the set.
- [ ] Women/men visuals avoid sexualized or aggressive stereotypes.
- [ ] Every card can be cropped to 4:5 without losing the route promise.
- [ ] No image uses shame, diagnosis, or fake transformation as the sales device.
