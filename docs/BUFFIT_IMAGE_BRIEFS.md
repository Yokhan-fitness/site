# BUFF IT Image Briefs

Нужны самостоятельные рекламные арт-объекты BUFF IT, а не стоковые фитнес-сцены и не буквальные иллюстрации первого порядка. Каждый кадр обязан отличаться от соседних локацией, светом, камерой, действием и визуальной метафорой, чтобы одновременно раскрывать позиционирование и помогать навигации.

## Общие правила

| Параметр | Требование |
|---|---|
| Арт-направление | Современный campaign key art: один сильный образ, глубина, движение, материальность и неожиданный визуальный ход. Не `wellness`, не Canva, не cottagecore, не каталог фотостока. |
| Идея | Не иллюстрировать подпись буквально. Сначала сформулировать метафору и навигационную роль, затем строить сцену вокруг них. |
| Свет | Для разных ролей разные световые условия. Запрещено повторять один тёплый бежевый свет на всей странице. |
| Локация | Локация обязана раскрывать аудиторию или задачу. Офис, квартира и спортзал не используются как универсальный фон по умолчанию. |
| Люди | Привлекательные, живые, уверенные персонажи с правдоподобной спортивной формой. Реализм не означает усталый вид, сутулость или безликую бытовую документальность. |
| Техника | Любое упражнение проходит отдельную полноразмерную проверку опоры, суставов, позвоночника, хвата и оборудования до размещения. |
| Бренд | Если появляется BUFF IT, только капсом и шрифтом Unbounded. Не добавлять случайные надписи и псевдоинтерфейс. |
| Композиция | Для каждого placement заранее фиксируются desktop/mobile crop plan и зона под текст. Мобильная версия не получается случайным обрезанием desktop. |
| Запрещено | Буквальный монтаж «четыре подписи — четыре стоковых сцены», пастельная wellness-карта, пины и иконки первого порядка, блокноты, гантели, чёрная одежда/фон, fake luxury, «успешный успех». |

## P0-01. Women / Programs

| Поле | Описание |
|---|---|
| Где используется | `women.html`, `programs.html`, карточки «Топ ягодицы», «Похудеть без отката», «Подготовь тело к новому образу». |
| Эмоция | «Я могу выглядеть лучше в своей обычной жизни, без стыда и марафона на износ». |
| Идеальный кадр | Женщина дома делает ягодичный мост/румынскую тягу/контролируемый squat с резинкой или гантелью. В кадре тёплый интерьер, коврик, полотенце, бутылка, мягкий свет. Не поза для рекламы белья, а уверенное движение. |
| Текст рядом | «Фигура, которую приятно носить каждый день», «Топ ягодицы», «Похудеть без отката». |

## P0-02. Men / Work Body

| Поле | Описание |
|---|---|
| Где используется | `men.html`, `training.html`, мужские program cards. |
| Эмоция | «Тело не отстаёт от головы, работы и статуса». |
| Идеальный кадр | Мужчина после работы дома: рядом рабочее место, монитор, кресло, тёплая лампа. Он делает тягу гири, отжимание на опоре, тягу резинки или контролируемое движение для спины. Фокус на плечи, спину, осанку, без качковского пафоса. |
| Текст рядом | «Выглядеть сильнее. Двигаться легче», «Тренировки для тех, кто зарабатывает головой». |

## P0-03. Health / Safe Start

| Поле | Описание |
|---|---|
| Где используется | `health.html`, `safety.html`, health/scenario cards. |
| Эмоция | «Со мной не будут героически ломать тело, сначала разберутся спокойно». |
| Идеальный кадр | Человек дома делает мягкую мобилизацию спины/таза/плеч, рядом ролл, мяч, коврик, вода. Не врачебный кабинет, не больница, не тревожная боль. Кадр должен давать безопасность и компетентность. |
| Текст рядом | «Безопасный старт», «Не путать спорт и риск», «Когда сначала надо разобраться с ограничениями». |

## P0-04. Food / Everyday Nutrition

| Поле | Описание |
|---|---|
| Где используется | `nutrition.html`, BUFF IT FOOD cards. |
| Эмоция | «Еда помогает форме и жизни, а не становится второй работой». |
| Идеальный кадр | Тёплая кухня или стол: простая нормальная еда, белок, овощи, вода, контейнеры, список покупок. Без фитнес-салата на белом фоне и без диетической тревоги. |
| Текст рядом | «Еда должна помогать форме, а не срывать её», «Корзина под цель», «Замены без паники». |

## P0-05. Calls / First Step

| Поле | Описание |
|---|---|
| Где используется | `calls-access.html`, `start.html`, CTA-блоки «разбор» и «первый шаг». |
| Эмоция | «Можно спокойно разобраться и не начинать наугад». |
| Идеальный кадр | Домашний рабочий стол: ноутбук/телефон с размытым планом тренировки или Telegram route, блокнот, лампа, бутылка BUFF IT. Человек не обязательно в кадре, можно руки у ноутбука. Важно ощущение ясности, а не технички. |
| Текст рядом | «Когда проще один раз разобрать, чем месяц гадать», «Подобрать старт». |
